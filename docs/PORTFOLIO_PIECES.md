## 02. Creative Studio

**Project period:** Active in 2026  
**Featured:** 2026  
**My role:** Founder / application engineering · ListPull

A browser-based image and SVG editor with a layered canvas, drawing tools, image adjustments, and file exports.

Creative Studio is an image and vector editing application built around a browser canvas. The workspace supports imported photos and SVG files, editable text and shapes, grouping, layer order, alignment, image adjustments, and exports. It also has undo and redo, document sizing, cropping, and an optional on-device AI design assistant. These features involve more than placing controls around an image. The editor has to track the state of each object, apply changes without losing the original artwork, and keep the canvas, selection handles, and property fields in sync. Working on this kind of application draws on interface design, JavaScript, file handling, and the practical details of editing graphics. I included it in my portfolio because it represents how I approach interactive software: give people precise controls, handle complicated behavior underneath, and keep the workspace understandable even as more features are added.

- Open the editor: https://listpull.com/studio/image-editor.html

## 03. Video Studio

**Project period:** Active in 2026  
**Featured:** 2026  
**My role:** Founder / application engineering · ListPull

A browser-based video editor with multiple timeline tracks, clip trimming, titles, audio, keyframes, and export settings.

Video Studio is a media editing application with a timeline, a preview monitor, and separate tracks for video, overlays, titles, and audio. It handles imported footage and images, trimming and splitting clips, speed and volume changes, cropping, transitions, keyframe animation, voice recording, and export settings. It involves media handling, detailed interface behavior, and coordinating controls that depend on each other. ## 06. Forecast Lab

**Project period:** Active in 2026  
**Featured:** 2026  
**My role:** Founder / forecasting application engineering · ListPull

A time-series forecasting application with CSV imports, observed-data charts, projected values, and model checks.

Forecast Lab is an application for working with time-series data. It takes sample values, manually entered observations, or imported CSV records and produces a chart that separates past data from estimated future values. It also lets users change the forecast length, inspect the projected numbers, and download results. The public version uses a simple time-series model and compares past errors with a basic last-value forecast. That check matters because a prediction is only useful if its limits are clear. I've also worked on forecasting services using Node.js and ARIMA models, including caching and data-provider integrations, which gives this project a deeper engineering connection. The application demonstrates the interface side of that work: importing records, keeping values in time order, updating charts, and showing uncertainty without presenting a forecast as a fact.

- Try Forecast Lab: https://listpull.com/studio/forecast.html

## 08. Clinic Recommendations

**Project period:** 2023–2025  
**Created:** 2023  
**My role:** Software engineering manager · Accenture

A React clinic-recommendation feature connecting lab data with AWS processing, PostgreSQL, and semantic search.

At Accenture, I led engineering work on a clinic recommendation feature for Bristol Myers Squibb. The feature was added to an existing React application and used lab information to help surface relevant clinic options. On the back end, the work involved AWS Step Functions, Lambda, PostgreSQL, Bedrock embeddings, and OpenSearch. My role included helping the team connect these pieces and make the result usable in the application people already had. What I took away from this project is that AI features don't live on their own. They still need dependable data, clear rules, careful testing, and an interface that makes sense to the person using it. This was also sensitive work, so the portfolio doesn't show private data or a real client screen. The diagram is a simplified view of how the systems fit together, not a copy of the production setup.

**Created:** 2019

The Bureau of Labor Statistics website modernization using React, government data APIs, accessible charts, and publishing tools.

At BAE Systems, I helped modernize the public Bureau of Labor Statistics website for the U.S. Department of Labor.
